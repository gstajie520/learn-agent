# 最小评估集

跨阶段回归基线。这个模块里只有一个测试类 `learn.agent.eval.MinimalEvaluationSetTest`，
它不测某一课的细节，只钉住「已经学会的能力现在还在」。

## 为什么单独一个模块

它依赖**全部上游模块**，所以必须排在 reactor 最末端，且**不能被任何模块依赖**。
如果把它塞进某一课的模块里，那一课就会反向依赖后面所有课，依赖图立刻出现环。

编号用 `99` 而不是接着 `10`，是为了让「它永远在最后」这件事从目录名就能看出来，
后面新增阶段 10、11、12 时不需要重新编号。

## 运行

```powershell
Set-Location '.\learning\agent-java-learning'
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-17.0.18'
mvn -o -pl 99-minimal-eval -am test
```

`-am` 会把上游模块一起编译，所以这条命令实际上就是全量回归。

## 怎么维护

每进入一个新阶段，往里面加 3-5 个覆盖新能力的用例。加之前先问一句：
**这条用例失败时，我能不能立刻说出是哪个能力退化了**。答不上来的用例属于单元测试，
应该留在对应课的模块里，不该进评估集。

评估集的价值在改代码之后：先跑它，再看单元测试。它绿了说明没砸旧能力，
它红了说明这次改动动到了别人的地基。
