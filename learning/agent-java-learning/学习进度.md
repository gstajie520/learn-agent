## 关键里程碑

### 🎯 阶段 10 前 4 课的架构意义

1. **证明了 Hook 扩展点的边界**
   - Hook 能处理审计、拦截、副作用注入
   - 但**不能处理请求级临时上下文**（会污染历史）
   - 补上了 `ToolRoundObserver` 扩展点

2. **统一了三个循环的漂移**
   - `AgentLoop`、`GuardedAgentLoop`、`HookedAgentLoop` 曾经漂移
   - 用 `LoopBehaviorParityTest` 钉住行为一致性

3. **建立了文件操作的安全边界**
   - `WorkspaceGuard` 是后续所有文件操作的基础
   - 两道关（词法 + 物理）缺一不可

4. **完成了上下文预算管理的基础设施**
   - 四级压缩策略：从最简单的移除到最昂贵的总结
   - 配对验证：确保压缩不破坏工具调用的完整性
   - Artifact 持久化：大型产物不占用上下文预算

4. **完成了域重映射的第一阶段**
   - 教材：文件 / shell 工作区
   - Java 侧：场景 / 设备（领域概念）
   - 阶段 10 后三课会继续深化这个映射
