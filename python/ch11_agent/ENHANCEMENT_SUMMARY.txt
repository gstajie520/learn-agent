五、核心概念梳理
===============================================

三种故障类型：
  1. 输出截断（finish_reason == "length"）
     → 升级预算 8000→64000，仍截断则续写

  2. 输入过长（ModelPromptTooLongError）
     → 保留 system message，压缩其余历史

  3. 临时故障（429/529）
     → 429 遵守 Retry-After，529 连续 3 次切 fallback

设计模式识别：
  1. 适配器模式：供应商错误归一化
  2. 策略模式：ModelRequestExecutor 接口
  3. 状态模式：RecoveryState 可变状态
  4. 装饰器模式：RecoveryManager 包装 ModelClient
