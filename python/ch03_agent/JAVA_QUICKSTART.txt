第 2 步：读权限策略核心（20 分钟）
---------------------------------
打开 core/permissions.py，按顺序阅读：
  1. PermissionDecision    → 四态行为（allow/deny/ask/passthrough）
  2. PermissionRequest     → 不可变请求快照
  3. PermissionRule        → 匹配器 + 行为 + 原因
  4. PermissionPolicy      → 合并规则、边界、审批、审计

重点理解：
  - Literal["allow", "deny", "ask", "passthrough"] = 字面量类型（类似枚举）
  - Callable[[Request], bool] = Java Predicate<Request>
  - frozen=True = 不可变 record
  - _strongest() 冲突合并：deny > ask > allow

权限决策流程：
  工作区边界检查 → shell 默认 ask → 规则评估 → 合并候选 → 审批收敛 → 审计记录

核心概念速记
---------------------------------
四态行为 = allow（放行）/ deny（拒绝）/ ask（需审批）/ passthrough（无规则参与）

fail-closed 原则 = 审批器/规则异常时默认 deny（安全优先）

决策合并 = _strongest(candidates) 选最保守：deny > ask > allow

工作区边界 = 拒绝绝对路径、.. 片段、符号链接逃逸、Windows 保留名

审计不可绕过 = audit.record() 失败时向上抛出，阻止工具执行

权限层位置 = prepare() 之后、invoke() 之前，拒绝时仍要生成配对 tool 消息
