第 3 步：浏览支撑文件（15 分钟）
---------------------------------
快速浏览三个文件，了解数据结构：
  - core/messages.py  → 消息 DTO（SystemMessage/UserMessage/AssistantMessage/ToolMessage）
  - core/tools.py     → 工具接口（ToolRegistry/ToolDefinition/ToolResult）
  - core/model.py     → 模型接口（ModelClient/ModelRequest/ModelReply）

不要深入细节，知道有什么就行。


核心概念速记
---------------------------------
Agent 循环 = while (未达上限) { 调用模型 → 有文本就返回 → 有工具就执行 → 继续 }

授权器 fail-closed 原则 = 授权系统故障时默认拒绝（安全优先）

消息配对契约 = 每个 assistant.tool_calls[i] 必须有对应的 tool 结果

为什么要 max_turns = 防止模型无限调用工具（成本和性能保护）
