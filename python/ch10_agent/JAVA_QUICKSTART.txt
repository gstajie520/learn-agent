核心概念速记
---------------------------------
动态 Prompt = 每轮从运行态读取最新状态（工具/记忆/Skill）

固定顺序 = identity → tools → workspace → skills → memory

严格 JSON = 拒绝循环引用、NaN/Infinity、非字符串键、非 JSON 类型

实例级缓存 = 基于稳定 JSON 键，避免重复序列化（但不跨 Agent 共享）

Provider 接口 = 封装依赖，零参数调用（类似 Supplier<String>）

引用传递 = 保存对象引用而非快照，感知运行态变化

常见问题速查
---------------------------------
Q: 为什么不在 Bootstrap 时生成一次 Prompt 就固定？
A: 因为工具可能动态注册、记忆每轮选择不同、Skill 按需加载。

Q: 为什么 context 必须是严格 JSON？
A: 作为缓存键必须保证稳定性，拒绝循环引用和不可序列化值。

Q: 为什么缓存放实例字段而不是全局变量？
A: 避免跨 Agent 污染，每个 AgentRunner 有独立运行态和缓存。

Q: 为什么 Provider 保存对象引用而不是值快照？
A: 要感知运行态变化，下一轮读取最新工具列表和选中记忆。

Q: 为什么 _stable_json 要 sort_keys=True？
A: 保证相同内容得到相同 JSON 字符串，不同构建路径不影响缓存。
